## phone_code.php CORS 修复接通客户端「刷新短信验证码」（2026-11-21 11:39）

- **用户报「获取短信验证码失败: Failed to fetch」**——定位：客户端编辑账号「绑定手机号」字段（bind_phone）本来就设计成**填链接**（文案误导，报错提示「未配置短信验证链接」），账号列表「短信验证」列的刷新按钮会 `fetch(bind_phone)`（带 Content-Type: application/json → CORS 预检）。phone_code.php 初版无 CORS 头 → Tauri 网页 fetch 被拦。**不是指纹浏览器的问题**（fetch 发生在客户端 webview）。
- **修复**：phone_code.php 加 `Access-Control-Allow-Origin: *` 等三头 + OPTIONS 预检 200；**智能格式**——请求带 application/json 头（客户端）自动回 JSON（`json.code` 正是客户端解析首键），浏览器普通打开回 HTML 大字页。fmt 参数仍可显式覆盖。
- **实测三项全过**：OPTIONS 预检 200 带全套 CORS 头；JSON 头 GET 回 `{"success":true,"code":"418915",...}` 带 allow-origin；普通 GET 回 HTML。
- **用户用法**：把 `https://yacm.xin/tk/phone_code.php?k=yacm-sms-2026` 填进编辑账号「绑定手机号」→ 账号列表点「短信验证」列的刷新按钮即出码；同一条链接浏览器打开就是人看的自动刷新页面。客户端解析顺序 json.code → data.code → sms_code → 正则 \d{4,6}。
