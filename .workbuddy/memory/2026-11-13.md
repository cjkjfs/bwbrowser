## 查证：为什么「Cookie 来源不是该账号」仍有视频嗅探按钮（YouTube sqyacmyxgs@gmail.com）

结论：**嗅探扩展注入与 `settings.cookie_account_id` 完全无关，是两条独立链路。**

- 嗅探注入只看「扩展分配绑定」：`extension_user_assignments.json` →
  `apply_owner_assignments`/`sync_user_group_for` → 生成自动分组 `__user_<uid>[_acct_<aid>]`
  → 写回 `profile.extension_group_id` → 启动时 `install_extensions_for_profile` → `--load-extension`。
- 该账号实锤：云端 `id=3873`、`account_name=SpongeBob Moments`、`login_account=sqyacmyxgs@gmail.com`、
  **`owner_id=14`**；profile `SpongeBob Moments_3873`(`6bccb2aa-e1c8-4e04-b529-651a77582075`)，
  `extension_group_id=053fbd38-d047-4fae-a79c-cd562c0a6633` = 分组 `__user_14_acct_3873`。
- 关键数据：`extension_user_assignments.json` 里有一条
  `{"extension_id":"fd358ba0-47c7-4a37-bba8-fc3288392ae3"(视频嗅探下载), "user_id":14, "account_ids":null, "vps_login":true}`
  —— `account_ids: null` = **不限定账号**，user 14 名下所有账号（含 3873）都注入。
- 机制细节（`assignment_applies` 570-588）：`account_ids:None` → user 匹配即生效（名下全部账号 + 爆文库）；
  `account_ids:Some(list)` + 有账号上下文 → 只按账号 id 匹配；`account_ids:Some` + 无账号上下文 → 仅 `vps_login==true` 生效。
- 设计注记（`browser_runner.rs:700-708`）：**云端账号启动默认不注入扩展**（减小注入面/降风控敏感度），
  但 `__user_` 自动分组是显式例外。所以「云端账号 + 管理员不限账号分配」= 必然注入。
- 关闭方式：把该绑定改成指定 `account_ids`，或删除 user 14 的分配；取消后 `apply_owner_assignments`
  会自动摘掉 profile 上残留的 `__user_` 分组。

## 查证：嗅探扩展是否影响指纹

- **不改变任何指纹参数**：UA / UA-CH / screen / window / canvas / WebGL / 字体 / 时区等全部来自指纹配置
  （`wayfern_manager.rs` 拼 arg），扩展只走标准 `--load-extension={paths}`（2916 行，与手动装扩展同链路）。
- **但会增大「可探测面」（诚实结论）**：
  - `hook.js` 由 `content.js` 用 `chrome.runtime.getURL("hook.js")` +
    页面 `<script src>` 注入 MAIN world → 页面可见 `window.__bwvsHooked`,
    可校验 `window.fetch.toString()` 非 native，资源时间线里出现 `chrome-extension://<id>/...`；
  - `manifest` 的 `content_scripts.matches = ["<all_urls>"]` → **每个站点**都注入；
  - 悬浮球在 `attachShadow({mode:"closed"})` 内，主 world 查不到（所以不能用「查不到 .fab」判断未注入）；
  - 代码里自己也写了：PayPal 启动完全跳过注入（`browser_runner.rs:736-737`「any injected extension widens
    the fingerprint that PayPal's security check reacts to」）。
- 可选的收敛方向（未实施）：把 content script `matches` 从 `<all_urls>` 收窄到视频站点 + 常见站点；
  或云端账号启动时按需注入（只有真正要下载时再装）。
