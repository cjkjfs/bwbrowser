## 远程管理 macOS 双屏切换不生效（2026-11-23 诊断+修复）
- **现象**：被控端 macOS 双屏，viewer 点「屏幕切换」还是同一个画面。
- **链路排查**：控制页=VPS remote_app.php（cycleMonitor→set_monitor）；被控端 relay.rs SetMonitor 分支正常（切屏+invalidate_frame+set_active_display）；macOS capture.rs capture_screen_monitor(index) 正常。**根因在 H264 编解码两端配合**：
  - **同分辨率双屏**（最常见）：relay.rs SetMonitor 只 invalidate_frame 不置 force_key；encode.rs encode_h264 的编码器按「尺寸变化」才重建（recreate 判定），同尺寸切屏→编码器不重建→继续输出参考旧屏内容的 P 帧→画面纹丝不动（最长 240 帧≈8 秒后才等到周期 IDR）。
  - **异分辨率双屏**：新编码器首帧=新 IDR，但 viewer handleH264Frame 只在 h264State 为空时创建解码器（configure 一次永不再配）→ 旧解码器解新流报错→IDR 丢弃→后续 delta 帧无参考全丢→~8 秒黑洞。
- **修复**：
  - **relay.rs**（本地，需编译）：SetMonitor 变更时加 `self.force_key = true`（同分辨率也能立刻出新 IDR）。
  - **remote_app.php**（VPS，备份 .bak_20261123_monitor，php -l 通过，即改即生效）：①h264State 增加 h264LastW/H/Sps 跟踪，帧尺寸或 SPS 变化即 close 旧解码器重建（本帧非 IDR 则等下个 IDR）；②monitor_changed 处理里立即丢弃旧解码器 + sendMsg request_keyframe（双保险）。
  - 本地 LAN viewer（web/client.js）无切屏 UI（display_count Windows 恒 1），未动。
