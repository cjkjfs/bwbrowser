## 🔌 5个PHP接上节点代理 + 多节点自动切换（2026-11-07 下午追加）

### 实现（vless_proxy_lib.php 新增 3 个核心函数）
- `vless_curl_apply_proxy($pdo,$ch,$url)`：给任意 curl 应用节点代理，仅对 host 正则
  `/googleapis\.com$|google\.com$|youtube\.com$/` 生效，开关 `vless_proxy_curl_enabled`，
  兼容 PHP7(资源)/PHP8(CurlHandle) 句柄
- `vless_restart_service($pdo,&$err)`：CLI 直接 systemctl，FPM 走 agent 队列
- `vless_failover_enabled` / `vless_failover_check($pdo,&$log)`：当前节点不通时依序尝试其它节点，
  成功即切为默认，全部失败回滚原节点
