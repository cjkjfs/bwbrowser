## Magpie 添加 Trae 账号失败 — 修复
- **背景**：用户 Magpie 部署在 VPS(47.93.197.114:220)，浏览器在本机 Windows。面板 3426，网关 3425。
- **根因**：`@magpie-community/opencode-trae-auth` 插件把 Trae OAuth 回调写死为
  `http://127.0.0.1:<随机端口>/authorize`（`index.mjs:706` `server.listen(0,"127.0.0.1",resolve)`），
  回调 HTTP 服务监听在运行 Magpie 的 VPS 的 127.0.0.1。浏览器在本机，回跳的本机 127.0.0.1 够不到 VPS
  回调端口 → 令牌丢失 → 加号失败。端口随机导致无法预占固定隧道。
- **修复**（方案已落地）：
  1. VPS 上把插件 `server.listen(0,…)` 改为 `server.listen(38905,…)`（sed 打补丁，已备份 .bak_orig）。
  2. `systemctl restart magpie` 重新加载插件（新 PID，网关 3425 & 面板 3426 正常）。
  3. 本机起 SSH 隧道：`ssh -N -L 38905:127.0.0.1:38905 root@47.93.197.114 -p 220`，
     把本机 38905 转发到 VPS 38905，回调经隧道到达 VPS 插件。
- **风险**：插件是 `@latest`，`magpie plugin update` 会覆盖补丁；更新后需重打。
- **文档**：`D:\bian\vps\_work\magpie_trae_login_fix.md`（含一键命令、回滚、故障表）。
- **关键信息**：VPS SSH root@47.93.197.114:220，私钥 `D:ian\vps\47.93.197.114_id_ed25519`。
  页面密钥在 `magpie_admin.php`：面板 `http://47.93.197.114:3426/?k=UAPti8ayai3Ek9e7oHb74kZX`。
