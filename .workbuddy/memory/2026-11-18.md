## NSIS 更新装完不自动启动主程序（bug 修复，2026-11-18）

用户问「安装后会启动主程序吗」。核查 Tauri v2 官方 NSIS 模板（installer.nsi）：
- `/UPDATE` 只跳过卸载/保留快捷方式，不触发启动；自动启动仅当 silent/passive 模式下带 `/R` 参数（.onInstSuccess 里 GetOptions "/R"→RunAsUser）。
- `AUTOLAUNCHAPP` 是 WiX/MSI 模板机制，NSIS 不存在。app_auto_updater.rs 注释里 "AUTOLAUNCHAPP flags" 是误导。
- 项目 targets=["app","dmg","nsis","deb","rpm","appimage"]，无 msi → Windows 分发 NSIS exe → 修复前静默更新装完主程序不启动（程序"消失"）。
- **修复**：restart_application exe 分支参数 `/S /UPDATE` → `/S /UPDATE /R`。MSI 分支 `/quiet /norestart /promptrestart AUTOLAUNCHAPP=True` 本来就会自动启动，不动。
- 另一处 1261 行 nsis_args（/S 无 /R 的 fallback 静默安装路径）未动。
- 待重编译生效。
