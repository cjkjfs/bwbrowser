## 【下午 15:26】macOS 151 补丁版指纹可用性结论（用户问询，纯问答不涉及改动）

用户问：a) 不改（原版内核）macOS 指纹能否正常用；b) 现在 Windows 有 token、macOS 是不是就不能用了；c) "拿不到 token → CDP 不能用 → 兜底 DOM → 浏览器正常开"是否成立。

### 已核实的机制（代码 + 服务器日志）
1. **token（wayfern_token）≠ 浏览器能否启动**。`wayfern_manager.rs` 只在**跨 OS 指纹**需要 token：`get_wayfern_kernel_token()` 拿不到且 `claimed OS != host OS` 时返回 `WAYFERN_CROSS_OS_REQUIRES_PLAN`（同 OS 指纹完全不需要 token，直接放行）。token 由 `wayfern_token.php` 发给付费账号（bjz/gaz/lsj…），日志持续 `plan=1 sub=bjz`。
2. **验证端点是平台无关的**：`api_auth_wayfern_verify.php`（151/.71 用）验签后返回 `plan=1`，不区分 Windows/macOS。服务器 `logs/wayfern_verify.log` 目前全是 123.10.x 客户端（Windows），**尚未看到 macOS 真机记录**。
3. **"CDP 不能用 → 兜底 DOM → 浏览器正常开"** 是**内核自动化网关**按付费档位判的（不付费时 `Runtime.evaluate` 回 "requires a paid plan"，程序端 `cookie_sync.rs:1206` 检测到后走 `DOM.getDocument+querySelector` 兜底）。程序端 Rust 只对**跨 OS** 才拒绝启动，且是"拒启"不是"开了再兜底"。156 的自动化 gate 曾被逆向解锁（5 补丁），151 macOS 只打了公钥+URL 补丁，**自动化 gate 未解**（ARM64）。

### 最终结论（对 macOS 151 补丁版）
- Mac 上**刷 macos 指纹（同 OS）** → 不需要 token，浏览器正常开、CDP 正常、不兜底 DOM。
- 仅**跨 OS 刷指纹（如 Mac 上刷 Windows）** 且无 token 才被拒启动 → 那才会碰"CDP 受限/兜底 DOM"的边界。
- Windows 有 token = 账号是付费档；macOS 刷同 OS 指纹更宽松。
- **待办不变**：Mac 真机刷 macos 指纹后，看服务器 `logs/wayfern_verify.log` 是否出现 macOS 端 `plan=1` 记录，即可确认打通。

## 远程被控端 PowerShell 弹窗隐藏（已完成）

用户反馈：登录时弹两个 PowerShell 窗口，问能否去掉/隐藏。

### 根因
`remote_agent/mod.rs` 的 `ensure_windows_firewall_rule()`（启动被控端时添加 Windows 防火墙入/出站规则）用 `std::process::Command::new("powershell").args(["-Command", &ps]).output()`，**未加 `CREATE_NO_WINDOW`**，因此每次 `start_agent`（登录/权限 watcher `reconcile` 自动拉起）都会闪一个黑框。

**全项目唯一一处无隐藏的 powershell 调用**：grep `Command::new("powershell")` 仅 `mod.rs:451`，其余（app_auto_updater/cmd、proxy_runner、xray/vpn/video/wayfern 等）均已加 `CREATE_NO_WINDOW` 或 DETACHED_PROCESS。

### 修复
`remote_agent/mod.rs` `ensure_windows_firewall_rule` 内加：
```rust
use std::os::windows::process::CommandExt;
const CREATE_NO_WINDOW: u32 = 0x08000000;
// .creation_flags(CREATE_NO_WINDOW)
```
函数本身是 `#[cfg(windows)]`，块内 use + 链式 `.creation_flags(CREATE_NO_WINDOW)` 合法。不编译（用户自编译）。

### 调用链（登录时弹窗来源）
登录/权限检查 `client_login` 成功 + 有远程权限 → `reconcile()` → `start_agent()` → `ensure_windows_firewall_rule(cfg.port)` → 弹 PowerShell → 已隐藏。

### 用户看到的"两个"窗口说明
该函数单次只弹一个；若此前失败重试或权限被 UAC 挡再启会再弹，但唯一确定会弹且未隐藏的就是这一处 PowerShell，已一并解决。
